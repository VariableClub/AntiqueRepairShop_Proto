## 3. 빌드 녹화 체크 (완료 기준: 소리와 진동이 사건마다 다른 녹화)

Quest 녹화에는 진동이 찍히지 않는다. 화면 구석에 컨트롤러를 쥔 손이 보이게 휴대폰으로 함께 찍거나, 진동을 느낄 때 말로 표시한다.
한 번 녹화에 억지 손상 경로까지 넣으면 MEM-02(갈라진 소리)와 MEM-07(영상 마스크), ★ 알파 기준 ③도 같이 채울 수 있다.

- [ ] 맞는 조작: 눈 단추를 눈 자리에 맞춤 → 맑은 소리 + 짧은 진동 1번
- [ ] 틀린 조작: 단추를 틀린 자리에 댐 → 둔탁한 클릭 + 진동 2번
- [ ] 억지 경고: 꺼내기에서 천천히 세게 당김 → 삐걱 소리와 진동이 점점 세짐
- [ ] 경고 후 힘 빼기 → 삐걱 소리가 0.15초 안에 줄어듦
- [ ] 억지 손상 2단계 (끝까지 당김) → 찢김 소리 + 센 진동 3번, 배가 더 벌어진 모델 (손상 A)
- [ ] 억지 손상 3단계 또는 4단계 하나 → 뭉침 또는 금 소리 (2단계와 소리가 다름)
- [ ] 단계 완료 → 완료음 + 기억 소리 한 겹 추가 (손상 단계는 갈라진 소리)
- [ ] 잘못된 처리 자리에 놓기 → 튕김 소리 + 진동 2번
- [ ] 반환 선반에 놓기 → 올려 둠 소리 + 진동 1번
- [ ] 손상 경로의 기억 영상에 마스크가 덮이는지 (MEM-07)
- [ ] 콘솔 로그 `[기억 소리] … (손상 단계 → 갈라진 소리)` 캡처

녹화 파일 이름: `Alpha_REP_SND_Damage_YYMMDD.mp4` → Drive에 올리고 WBS 메모에 이름을 적는다.

## 4. 에어팟 지연 실측 (SND-04)

방법 (`LatencyTest.cs`): 왼손 메뉴 버튼(≡)을 누르면 1초 간격으로 10번, 클릭 소리·양손 진동·작업대 위 빛이 같은 프레임에 난다.

1. 헤드셋 스피커로 한 번, 에어팟으로 한 번 실행한다 (유선 이어폰이 있으면 그것도)
2. 휴대폰 슬로모션(240fps 권장)으로 헤드셋 렌즈와 소리를 함께 찍는다. 에어팟은 휴대폰 마이크에 가까이 둔다
3. 빛이 켜진 프레임과 클릭 소리가 시작된 프레임의 차이를 센다 → `프레임 수 ÷ fps × 1000 = ms`
4. 콘솔의 `[지연 확인] 시작:` 줄(DSP 버퍼·출력 샘플레이트)도 함께 적는다

| 출력 장치 | 느낌 (빛·진동보다 늦게 들리나) | 슬로모션 측정 (ms) | DSP 버퍼 / 샘플레이트 | 판단 |
|---|---|---|---|---|
| Quest 3 스피커 | | | | |
| 에어팟 | | | | |
| 유선 3.5mm | | | | |

판단 기준 (가안, 기획서 20장): 억지 경고(삐걱)가 손 움직임보다 늦게 느껴지거나 측정값이 약 150ms를 넘으면, 전시·발표에서는 유선 이어폰이나 헤드셋 스피커를 쓴다.
슬로모션 영상 파일은 Claude에게 주면 프레임 차이를 계산할 수 있다.
