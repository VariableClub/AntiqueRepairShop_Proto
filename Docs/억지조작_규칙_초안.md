# 억지 조작 규칙 초안 + 기억 손상 처리 (1주차)

구현: `Assets/Scripts/ForceJudge.cs`, `Assets/Scripts/DamageLog.cs`, `Assets/Scripts/PartSocket.cs`
수치는 모두 ForceJudge 인스펙터에서 테스트하며 조정한다. 확정본은 "수선·억지 조작 규칙 확정 문서"(11/1)에서 정리.

## 기본 구조

- 떼어낼 물건(편지 등)은 몸통(곰 인형)에 붙은 **자리(소켓)** 에 꽂힌 상태로 시작한다.
  - 물건을 몸통 아래 자식으로 두고 ForceJudge를 붙이면, 실행할 때 그 위치에 자리가 자동으로 만들어지고 물건은 그 자리에 꽂힌다.
  - 직접 만든 소켓을 쓰려면 ForceJudge의 `slot` 칸에 넣으면 된다.
- 손으로 잡아 자리에서 뽑아내는 동안만 판정한다. 다시 자리에 가져다 놓으면 꽂히고, 다음에 뽑을 때 또 판정한다 (손상은 누적 유지).
- 눈 등 끼우기만 하는 자리는 `PartSocket`(눈은 `EyeSocket`)을 쓴다. 콜라이더는 실행 시 자동으로 트리거로 맞춰지고, 꽂힌 물건과 몸통이 서로 밀어내지 않게 충돌을 끈다.

## 억지 조작 판정

| 규칙 | 조건 | 기본값 |
|---|---|---|
| 1. 급하게 당김 | 자리 기준 손 이동 속도 ≥ `speedLimit` | 인스펙터 값 (현재 0.21 m/s) |
| 2. 거칠게 비틂 | 손 회전 속도 ≥ `twistLimit` | 540 도/초 |

- 속도는 최근 `speedWindow`(0.1초) 동안의 평균으로 잰다. 한 프레임 값은 트래킹·프레임 시간 흔들림 때문에 실제보다 몇 배씩 튀어서 쓰지 않는다.
- 자리를 기준으로 재므로, 다른 손으로 몸통을 같이 움직여도 억지로 치지 않는다.
- 한계의 `warnStartRatio`(50%)부터 진동 경고. 한계에 가까울수록 강해짐.
- 한계를 넘으면 손상 1단계 누적. `hitCooldown`(0.6초) 동안은 추가 손상 없음.
- 자리에서 `pullZone`(0.15 m) 이상 멀어지면 "꺼냄"으로 보고 판정 종료. 확 잡아채서 한 번에 빠져나가도 속도 판정을 먼저 한다.

## 손상 단계 → 기억 상태

| 단계 | 물건 상태 (회색 박스 색) | 기억 상태 (`MemoryState`) | 기억 연출 처리 (4주차 연동 예정) |
|---|---|---|---|
| 0 | 정상 (원래 색) | Intact | 그대로 재생 |
| 1 | 흠집 (노랑) | Blurred | 노이즈·색 바램 |
| 2 | 손상 (주황) | Fragmented | 기억 조각 1개 생략 |
| 3 | 파손 (빨강) | Broken | 왜곡·끊김, 결말 분기 후보 |

- 기억 연출 쪽에서는 `DamageLog.GetMemoryState(itemId)` 또는 `DamageLog.GetMemoryIntegrity(itemId)`(1 = 온전, 0 = 파손)만 읽으면 된다.
- 손상 이유 기록: `DamageLog.GetReasons(itemId)` (예: "급하게 당김 0.35m/s")

## 조작 방식

- 레이저(원거리) 잡기를 끄고, 손을 물건 가까이 가져가 직접 잡고 놓는 방식 (`DirectHandSetup`).
- 컨트롤러 모델 대신 회색 박스 손 모양 표시. 그립을 쥐는 정도에 따라 손가락이 접힘 (`GrayboxHand`).
- 억지 판정 물건은 잡은 위치 그대로 잡히도록 Dynamic Attach 사용 (세밀 조작용).

## 에디터 검증 결과 (가짜 손으로 자동 실행)

- 천천히 뽑기 (0.1 m/s): 손상 0단계로 꺼냄
- 다시 자리에 놓기: 자동으로 다시 꽂힘
- 확 잡아채기 (약 2.5 m/s): 손상 1단계 → 꺼냄
- 눈을 눈 자리에 가져가 놓기: 꽂힘 (`eyeFilled = true`)
