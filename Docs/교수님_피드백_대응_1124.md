## 피드백 3. 수선 행동과 결과의 연결

> 어느 부분을 어떻게 고쳤고 무엇이 달라졌는지 영상에서 읽히지 않음. 수선 부위·도구·동작·완료 조건을 연결하고 외형 변화를 보일 것.
> 도구를 놓치거나 잘못 써도 다시 진행할 수 있는지 확인할 것.

### 부위 · 도구 · 동작 · 완료 조건 · 외형 변화 (곰 인형, 기획서 13장)

| 단계 | 수선 부위 | 도구·부품 | 동작 | 완료 조건 | 보이는 변화 (이번 보완 포함) |
|---|---|---|---|---|---|
| 1 살피기 | 배 속 | 손 (곰 인형) | 흔들기 | 흔들기 2회 (15m/s²) | 배 쪽 들썩임 + 달그락 소리·진동. **완료 순간 배 부위가 한 번 빛남** |
| 2 꺼내기 | 찢어진 배 | 손 | 단추·쪽지를 배 밖으로 | 둘 다 배 밖 10cm | 단추·쪽지가 밖으로 나옴, 쪽지가 펼쳐져 N01 손글씨. **완료 순간 배가 빛남** |
| 3 넣기 | 찢어진 배 | 솜 (솜 상자) | 솜을 배 안에 넣기 | 솜 3번 | **솜을 쥐고 배에 다가가면 배 부위가 희미하게 빛남**, 솜이 틈 밖으로 보이게 부풀고 **몸이 조금씩 부풂(최대 4%)**. 완료 순간 빛남 |
| 4 맞추기 | 빈 눈 자리 | 눈 단추 | 눈 자리에 맞추기 | 1.5cm · 기울기 ±20° | **단추를 쥐고 다가가면 눈 자리가 빛남**, 딸깍 결합, 빈 눈 자국이 사라짐. 완료 순간 눈 자리가 빛남 |
| 5 맞추기(순서) | 배 봉합선 | 실 꿴 바늘 | 바늘구멍 4개 차례로 → 실 당기기 | 구멍 4개 + 실 15cm | 다음 구멍이 깜박임(기존), 실이 한 땀씩 보임, 완료 순간 배가 빛나고 **수선 후 모델로 교체** → 숨 쉬듯 움직임 → 기억 |

화면 글자 안내는 쓰지 않는다(11장). 부위 빛은 **맞는 것을 쥐고 다가갈 때**와 **단계가 끝나는 순간**에만 켜지는 반응이며,
가만히 있을 때 나오는 힌트 3단계 빛 점(작은 점)과는 크기·조건으로 구분된다.

코드: `BearRepair.cs` (수선 부위 빛), `BearView.cs` (솜에 따라 몸 부풂), 빌더 (부위 빛 구 생성, 솜 채움 크기 키움)

### 놓치거나 잘못 써도 다시 진행 (코드 확인 결과)

| 상황 | 지금 동작 | 근거 |
|---|---|---|
| 도구·부품·곰 인형을 바닥이나 손 닿지 않는 곳에 떨어뜨림 | 2초 뒤 시작 위치로 돌아옴 | `Grabbable` returnWhenLost (Q-008·Q-289) |
| 꺼낸 단추·쪽지를 떨어뜨림 | 꺼낸 자리 12cm 위로 돌아옴 | `PullOutJudge` (꺼낸 뒤 home 갱신) |
| 솜을 떨어뜨림 | 솜 상자 자리로 돌아옴, 상자는 계속 새 솜을 내놓음 | `CottonBox` |
| 바느질 중 바늘을 놓침 | 통과한 구멍 수는 유지, 다시 쥐고 다음 구멍부터 | `NeedleStitch.Passed` |
| 틀린 자리·순서 | 튕김 + 오류음, 횟수 제한 없이 다시 시도. 기억에는 영향 없음 | 11장, `FitSocket`·`NeedleStitch` |
| 억지 손상 | 손상은 남지만 진행은 계속됨 (게임오버 없음) | 11장 |
| 오래 막힘 | 10·20·30초(발견 단계 20·30·40초)에 힌트 3단계 | `HintDirector` (HNT-01~04) |

## 피드백 1. 타인의 기억과 나의 기억 구분

> 기억 장면에서 타인의 기억을 관찰하는지, 기억 속 인물이 된 것인지 불분명. 곰 인형 에피소드에서 누구의 기억인지 먼저 전달하고,
> 이후 자신의 기억 장면은 대사의 주어·호칭, 화면 구도, 진입 연출에서 차이가 나게 설계할 것.

### 이번에 반영 (곰 인형 = 타인의 기억)
- 기억 영상 직전, 숨 쉬는 곰 인형 옆에서 **곰 인형이 1인칭으로** 말한다: M01 ★가안 "…보여 줄게. 내가 기억하는 그 아이야."
  → '나' = 곰 인형, '그 아이' = 3인칭. 주인공의 기억이 아니라 **곰 인형이 본 장면**임을 영상 전에 알린다
- 영상은 지금처럼 **작업대 너머의 평면 화면**에서 재생: 플레이어는 작업대 앞에 선 채 바깥에서 바라본다 (구도 유지)
- 영상 뒤 P01 "누군가를 기다린다는 게 이런 느낌이었나?"는 주인공이 **본 것에 대한 반응**이다 (관찰자 위치 확인)

코드: `GameFlow.AfterRepair` (영상 전 M01), `AntiqueData.memoryOwnerLine`, 빌더 `AddFeedbackLines`

### 설계 원칙 (셋째 밤 손목시계 = 나의 기억, 3월 구현 MEM-08·12·13)

| 구분 | 타인의 기억 (곰 인형·카메라) | 나의 기억 (셋째 밤) |
|---|---|---|
| 누가 알리나 | 물건(도깨비)이 1인칭으로 "내가 기억하는 그 아이/그 사람" | 알려 주는 화자가 없다. 기억 속 인물이 **플레이어를 직접 부른다** |
| 주어·호칭 | 기억 속 인물은 3인칭("그 아이", "할머니") | 기억 속 인물이 2인칭으로 부름("너", 가족 호칭) ★호칭은 대본에서 확정 |
| 화면 구도 | 작업대 너머 평면 화면 (액자처럼, 테두리가 보임) | 화면 테두리 없음. 작업대·스탠드가 사라지고 **주변 전체가 기억 장면**, 인물 눈높이에서 플레이어를 바라봄 |
| 진입 연출 | 스탠드 외 소등 + 감정 조명, 작업대는 그대로 보임 | 손목시계 초침이 멈추며 **작업대까지 완전히 암전** → 장면 안에서 밝아짐 |
| 글자 위치 | 도깨비 글자는 물건 옆, 주인공 글자는 작업대 위 | 기억 속 인물 글자는 실루엣 옆 (18장 MemoryPerson) |
| 끝난 뒤 | 주인공 반응 대사 (관찰자) | 주인공 독백 없이 작업대로 돌아옴 → 엔딩 선택 |

다음 과제 결정 필요: 셋째 밤 화면 방식(360 영상·큰 곡면·3D 실루엣 중 무엇), 2인칭 호칭, 카메라(둘째 밤)도 타인의 기억 규칙을 그대로 쓸지

## 피드백 2. 기억의 결말과 보관의 의미

> 곰 인형을 옮기고 다음 밤으로 넘어가지만, 단순히 내려놓은 것인지 기억을 보관한 것인지 드러나지 않음.
> 왜 보관하는지 이야기로 전달하고, 위치와 완료 상태를 명확히. 놓이고, 짧은 마무리 대사나 기록이 남은 뒤 다음 밤으로.

곰 인형의 처리는 기획상 **반환**(그 아이에게 돌려보냄, 15장)이다. 보관(보존)은 카메라·시계의 기억 선반이다.
교수님이 '보관'으로 읽으셨다는 것 자체가 반환의 의미가 전달되지 않았다는 뜻이므로, 반환으로 읽히게 보완했다.

### 이번에 반영 — 놓기 → 확인 → 마무리 대사 → 기록 → 밤 전환
1. 곰 인형을 반환 선반(뒤쪽 작은 창 앞) 윤곽에 놓으면 그 자리에 앉혀지고, **1.2초 동안 놓인 모습을 보여 준다** (바로 넘어가지 않음)
2. 주인공 마무리 대사: C01 ★가안 "이제 그 아이에게 돌아가렴." — D02("나, 다시 그 아이에게 돌아가고 싶어")에 대한 응답
3. 선반 옆에 **수선 장부 카드**가 나타나고 이 밤의 기록이 쓰인다 (펜 소리)
   ```
   첫째 밤 · 곰 인형
   배 속의 단추를 찾아 다시 달아 주었다.     ← 손상이 있으면 journalDamaged 문장
   그 아이에게 돌려보냈다.                    ← processNote ★가안
   ```
4. 2.5초 뒤 밤 전환. 곰 인형은 암전 때 사라지고(주인에게 돌아감, D172), **장부 카드는 다음 밤에도 남는다**
5. 다음 밤: 출입문 옆 사진·꽃 (기존 PRC-05)

코드: `GameFlow.EndNight`·`WriteLedger`, `AntiqueData.closingLine`·`processNote`, 빌더 `BuildLedger`

### 다음 과제 결정 필요
- 반환을 더 분명히 할지: 반환 선반 작은 창 밖으로 빛이 빠져나가는 연출 등 (신주연, 라이팅·비주얼)
- `journalDamaged`(손상 시 문장)가 비어 있음 → 지금은 손상이 있어도 정상 문장이 나온다. 24장 문장 틀로 채우기 (AI-03, 신주연 문장)
- 장부 카드 위치·모양은 임시(회색 박스 종이). 수선 장부 페이지(AI-04, 4월)와 같은 물건으로 이어지게 할지

## 기기에서 확인할 것 (Unity → Quest)

빌더 실행: BasicScene을 연 뒤 「도깨비 > 3주차 알파 씬 만들기」. 콘솔에 `대사 표에 피드백 대사(M01·C01, 가안) 추가`가 한 번 나와야 한다.

- [ ] 콘솔 새 에러·경고 없음
- [ ] 3단계: 솜을 쥐고 배에 다가가면 배가 희미하게 빛남, 솜 넣을수록 배가 부풂
- [ ] 4단계: 단추를 쥐고 얼굴에 다가가면 눈 자리가 빛남
- [ ] 각 단계 완료 순간 그 부위가 한 번 빛남 (녹화에서 보이는지)
- [ ] 마지막 실 → 곰 인형이 숨 쉼 → M01 대사 → 기억 영상
- [ ] 반환 선반에 놓기 → 1초쯤 멈춤 → C01 → 장부 카드 기록 → 밤 전환 → 다음 밤에도 장부 카드가 남음
- [ ] 다시 진행: 바늘을 바닥에 떨어뜨림 → 2초 뒤 바늘꽂이로 → 다음 구멍부터 이어짐
- [ ] 다시 진행: 단추를 작업대 밖으로 던짐 → 돌아옴 → 4단계 진행 가능
- [ ] 다시 진행: 솜을 떨어뜨림 → 돌아옴, 솜 상자에서 새 솜
- [ ] 다시 진행: 곰 인형을 바닥에 떨어뜨림 → 매트로 돌아옴, 단계 유지
- [ ] 억지 손상 뒤에도 끝까지 완주, 장부 문장 확인
